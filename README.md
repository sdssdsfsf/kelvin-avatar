# Kélvin Avátar — منصة مشاركة بروفايلات ديسكورد والخلفيات

مشروع Full-stack مبني على Next.js App Router وPostgreSQL وPrisma وتخزين متوافق مع S3. الواجهة عربية وRTL. هذا مصدر تطبيق قابل للتشغيل، لكنه يحتاج خدمات خارجية مضبوطة قبل اعتباره جاهزاً للإنتاج.

## المتطلبات
- Node.js 20.9 أو أحدث (يفضل إصدار LTS مدعوم).
- PostgreSQL دائم.
- مساحة تخزين S3-compatible مثل Cloudflare R2 أو AWS S3.
- نطاق HTTPS عند النشر العام.

## التشغيل محلياً
1. انسخ `.env.example` إلى `.env` وأدخل القيم الحقيقية محلياً. لا ترفع `.env` إلى Git.
2. ثبّت الاعتماديات: `npm install`
3. أنشئ قاعدة PostgreSQL وأدخل `DATABASE_URL`.
4. أنشئ الجداول: `npx prisma migrate dev --name init`
5. أنشئ عميل Prisma: `npx prisma generate`
6. اضبط مساحة التخزين ومفاتيحها، واجعل `S3_PUBLIC_BASE_URL` يشير إلى نطاق صور عام أو CDN يقرأ من الـ bucket.
7. أنشئ المدير الأول بأمان: عيّن `INITIAL_ADMIN_USERNAME` و`INITIAL_ADMIN_PASSWORD` (16 حرفاً على الأقل) ثم شغّل `npm run admin:create`. احذف متغيرات الاعتماد بعد الإنشاء.
8. شغّل `npm run dev` وافتح `http://localhost:3000`.

## النشر
- انشر Next.js على خدمة تدعم Node.js.
- استخدم PostgreSQL مُداراً دائماً، لا قاعدة مؤقتة.
- استخدم R2/S3 أو ما يكافئه للصور؛ لا تعتمد على نظام ملفات الخادم المؤقت.
- اضبط جميع متغيرات `.env.example` في لوحة أسرار منصة النشر.
- نفّذ `npx prisma migrate deploy` في خطوة الإصدار ثم `npm run build`.
- فعّل HTTPS واضبط CORS في نطاق الصور لمنع مصادر غير مطلوبة، مع السماح بقراءة الصور للموقع.
- اختبر التسجيل والرفع والتنزيل والحذف وصلاحيات الإدارة قبل الإعلان عن الموقع.

## النسخ الاحتياطي
- PostgreSQL: استخدم `pg_dump` دورياً أو النسخ الاحتياطية المُدارة، واختبر الاستعادة.
- S3/R2: فعّل versioning أو نسخاً احتياطياً دورياً للـ bucket. احتفظ بسجلّ لمفاتيح الملفات.
- خزّن نسخة من ملفات البيئة في مدير أسرار آمن، لا داخل المستودع.

## ملاحظات أمان مهمة
- اسم المستخدم فريد بفضل قيد قاعدة البيانات. كلمات المرور تُجزّأ باستخدام bcrypt.
- جلسة الدخول عبارة عن JWT موقّع في cookie من نوع HttpOnly وSameSite=Lax.
- تأكد من وضع `SESSION_SECRET` عشوائي وطويل (32 حرفاً على الأقل).
- يجب ضبط rate limiting على مستوى منصة النشر أو Redis/WAF للإنتاج؛ عدّاد المحاولات داخل الذاكرة في هذا النموذج لا يشارك بين عدة عمليات ويُصفّر عند إعادة التشغيل.
- فحص الملفات يتحقق من MIME وتوقيع الملف والحجم. أضف فحص أبعاد الصور/فحص برمجيات خبيثة وحدود معدل الرفع قبل الإطلاق.
- في الإنتاج، أضف اختبارات تكامل، سياسة حذف بيانات، تدفق استعادة الحساب (يتطلب وسيلة تحقق اختيارية)، الإبلاغ عن المحتوى، وتدقيقاً أمنياً مستقلاً.
- يجب مراجعة سياسة الخصوصية وشروط الاستخدام قانونياً.
- الإعداد الافتراضي `CONTENT_MODERATION=true` يجعل المحتوى بانتظار موافقة الإدارة. اجعله `false` فقط إذا كنت تقبل النشر المباشر.
- الحذف في لوحة المستخدم يستخدم POST، بينما API تدعم DELETE مع التحقق من الملكية في الخادم.

## الوظائف المضمّنة
- تسجيل وإنشاء حساب عربي، جلسات آمنة نسبياً، حجز اسم المستخدم الفريد.
- رفع بروفايل (أفاتار + بنر) أو خلفية إلى S3-compatible storage.
- مكتبة عامة، بحث، ترتيب، صفحات تفاصيل، تنزيل الملفات الأصلية، وعدّ المشاهدات والتنزيلات.
- لوحة المستخدم وحذف المحتوى المملوك.
- لوحة إدارة للموافقة والرفض والتمييز وحذف المحتوى وإيقاف الحسابات وسجل تدقيق.
- تصميم متجاوب RTL وسياسة خصوصية وشروط استخدام وصفحة 404.

## حدود النسخة الحالية
لا تدّعي هذه النسخة أنها اجتازت اختبارات قبول أو تدقيقاً أمنياً مستقلاً. قبل الاستخدام التجاري، أكمل الاختبارات المذكورة، وركّب rate limiter مشتركاً، وراجع إعدادات التخزين العام وCORS، وأضف آلية الإبلاغ وإدارة الإعلانات والإعدادات إذا كانت مطلوبة.
